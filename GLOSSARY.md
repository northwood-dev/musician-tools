# Musician Tools

A practice companion for musicians: each user keeps their own Songlist of songs they work on, and can pull ready-made songs from a shared Catalog.

## Language

**Songlist**:
A user's personal collection of songs: the songs they added and practise.
_Avoid_: Library, repertoire

**Catalog**:
The shared pool of ready-made, pre-filled songs that any user can browse and add to their Songlist.
_Avoid_: Library, database

**Catalog entry**:
One song in the Catalog, described from one reference recording.
_Avoid_: fiche (in English text), track

**Reference recording**:
The one recording a Catalog entry is based on: its key, tempo, duration and official links all come from it.
_Avoid_: original, version

**Artist**:
The performer credited on the reference recording, whoever composed the song. A cover's artist is the covering band; a jazz standard's artist is the leader of the reference recording, not the composer.
_Avoid_: composer, author

**Album**:
The release the reference recording comes from, and only that: it never carries the performer's name.
